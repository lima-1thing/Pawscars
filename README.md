# Pawscars (毛孩奥斯卡) 宠物评选小程序

> 面向社群/朋友圈的宠物评选微信小程序，模拟“奥斯卡颁奖”分类评选体系，包含报名、初选划屏、8进4淘汰赛、4强巅峰德比与盛大颁奖典礼。

---

## 🐾 项目特性概览

1. **四大活动阶段流转**：
   - **报名期（7天）**：绑定活动ID（LDAP），提交单张毛孩靓照（自动裁剪正方形），支持多门类一次性勾选提交（复用照片+名字）。
   - **初选打投（7天）**：三大门类同页分行展示，每类横向左右滑动浏览候选照片，每类最多可挑选 8 张喜欢的毛孩。按被选次数前 8 名晋级（打平按时间戳更早者晋级）。
   - **8进4淘汰赛（7天）**：8 强按主人 LDAP 字母顺序 (A→Z) 固定配对（1v2、3v4、5v6、7v8），4 场 1V1 单败对决。上下堆叠卡片，点击即投票，动效反馈。
   - **4强巅峰德比（7天）**：4 强进行 6 场循环赛 (C(4,2))，自由投票窗口，按胜场与总票数决出冠亚季军。
   - **颁奖盛典**：领奖台（金银铜牌错落）、专属奥斯卡获奖证书生成（支持图片导出与分享）、全员贺词留言墙（每人限发1条）。

2. **三大自定义门类**：
   - 🍖 **干饭王者**：吃相最凶猛/最沙雕的选手（柠檬黄 `#FAC775`）
   - 🎭 **抽象王者**：行为无法用语言形容的选手（薄荷绿 `#9FE1CB`）
   - ✨ **颜值王者**：单纯靠脸吃饭的选手（淡紫色 `#CECBF6`）
   - *猫狗不限物种，均可跨门类报名；门类名称由管理员在后台自由编辑。*

3. **社群身份与隐私安全**：
   - **活动ID (LDAP)**：纯英文字母校验，全局唯一，已绑定用户自动识别。
   - **打码水印规范**：全局照片统一叠加角标——顶部为宠物名，底部为主人打码ID（如 `JENNIFER` -> `JE******`，前2位明文+剩余星号）。
   - **打平裁定原则**：全阶段统一采用“谁先达到该票数的时刻更早（以选票时间戳为准）”决胜。

4. **精致马卡龙设计系统**：
   - 浅粉背景 `#FBEAF0`、52px 对称猫狗头像圈 `#C7E4F5`、宫师姐发言人开场、柠檬黄 CTA 按钮 `#F9E27A`。
   - 首页一屏自适应排版（~650px），无需滑动即可见“我要提名”按钮。

## 🚀 运行与体验

### 方案 A：独立浏览器预览（无需安装微信开发者工具，立即体验）

项目内置了 375px 手机端视口的高保真 Web 模拟器，支持在任意浏览器中一键体验全部四大阶段流转与管理操作：

```bash
# 在终端中启动本地静态服务器
python3 -m http.server 3000 -d preview
```

打开浏览器访问 `http://localhost:3000` 即可：
- 顶部提供**阶段流转控制栏**（报名期 ⇄ 初选 ⇄ 8进4 ⇄ 4强德比 ⇄ 颁奖典礼）。
- 支持**模拟用户一键切换**（JENNIFER / ZHANG / ALICE 等），测试投票防重与“我的提名”私密查看。
- 可体验**照片生成、门类多选、爱心划屏、点击即投高亮打勾动效、证书生成导出、贺词墙发表**等全套流程！

### 方案 B：微信开发者工具中打开

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开微信开发者工具，点击 **导入项目**。
3. 项目目录选择 `/Users/lima/dev/Pawscars`（或本机项目根路径）。
4. AppID 可以选择自己的测试号或输入注册的测试 AppID。
5. 导入后即可在模拟器中实时编译预览。
6. 开箱即用：项目内置了存储抽象层，未配置云环境时会自动启用本地 Mock 存储，所有功能无缝运行！
7. 部署云开发时：右键 `cloudfunctions/` 下的各个云函数目录，点击“上传并部署：云端安装依赖”即可。
